Vice Cover Studio — turn your photo and a caption into GTA-style cover art, in the browser and offline. Multi-panel poster layouts, Vice City sunset and neon colour grades, bold display lettering, and one-step PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos stay on your machine; nothing is uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
