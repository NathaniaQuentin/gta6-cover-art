Vice Cover Studio — a GTA-style cover art maker web app. Drop in a photo, pick one of three layouts (Hero Split, Triptych, Four Corners) and one of four colour grades (Vice Sunset, Neon Nights, Ocean Drive, Noir Gold), write a caption, and export a PNG at 1080×1080, 1080×1350 or 1920×1080. All artwork is drawn procedurally in the browser — gradient sky, sun, seeded skyline with lit windows, palm silhouettes — with no Rockstar artwork, logos or fonts. The app is static files under `app/` and works fully offline; your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `app/` with any static file server.
